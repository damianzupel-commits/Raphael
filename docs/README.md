# docs/

- `CONTEXT.md` está en la raíz (`../CONTEXT.md`): lo primero que lee cualquier chat.
- `SPEC-FAMILIA.md`: spec completo de la Familia Raphael (orquestador y Raphaels).
- `ESTADO.md`: estado, decisiones y pendientes.
- `PIEZAS.md` y `BRIGADAS.md`: lista de piezas (un chat por pieza) y de brigadas.
- `design/harness-v2.md` y `design/orchestrator.md`: diseños aprobados del harness y del orquestador.
- `INVENTARIO-FASE0.md`: inventario del código existente y de los repos de Empresas.
- `log/<pieza>.md`: registro de sesiones de cada pieza (una entrada por sesión, con "Resumen de cierre").
