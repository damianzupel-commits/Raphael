# 3 · Mando

Cómo se dirige el proyecto: estado, decisiones, herramientas y el código viejo de referencia.

- `a-conocimiento/`: ESTADO, PLAN-MAESTRO, PIEZAS, BRIGADAS, SPEC-FAMILIA, instrucciones del coordinador y el log del mando y del revisor.
- `b-herramientas/`: la puerta del repo (`gate.bat` y `gate.py`) y las pruebas que cruzan piezas (`pruebas-contrato/`, `pruebas-e2e/`).
- `c-referencia/`: código existente de JarvisRemote y de Empresas viejo, solo lectura, más sus documentos (`docs-jarvisremote/`).
