# Contenido · c-salud
Lo que mantiene sana a la brigada, en tres carpetas:
- `pruebas/`: los tests de la brigada y la suite de contrato del harness (manifiesto válido, healthcheck, montar y desmontar, ningún import de otra brigada). Vacía hasta que se porte el código.
- `monitoreo/`: cómo se sabe si la brigada anda bien en marcha: healthcheck, métricas y alertas.
- `mantenimiento/`: lo que se corre de vez en cuando: regresiones, migraciones de datos y limpieza.
