# 1 · Harness

La base de todo. Sin el harness ninguna brigada corre, por eso las brigadas viven adentro.

- `a-conocimiento/`: todo lo necesario para conocer el harness a fondo (spec, diseño, qué se portó y el log).
- `b-codigo/`: el harness funcionando (`raphael-core`, contrato 2.1, 405 tests en `b-codigo/tests/`), con el panel de escritorio (`b-codigo/panel/`).
- `c-brigadas/`: todas las brigadas que se montan sobre el harness, con el orquestador como `00-orquestador`.
